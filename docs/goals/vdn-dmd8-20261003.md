# Goal: open-video VDN DMD8 8-step integration (A/B verify + land)

One-liner: cut MiniMax H3 per-shot generation time ~2x in agent-next/video-agent by adding the
OpenVDN DMD-distilled 8-NFE route as a settings profile, verified A/B against the proven 20-step
default on the RTX 5090 lab rig, judged by VLM.

Status: COMPLETE (measured: 1.81x @480p / 2.29x @768p wall-clock at equal judged quality;
receipts + judge verdicts committed).

Branch: feat/h3-vdn-dmd8-profile (pushed to agent-next/video-agent).

distillation (path A), wrap FreeVideo later if needed (path B), borrow planner ideas (path C).

  attribution requirement — blocks cloud deployment of these weights in those regions (owner
  decision needed before any cloud rollout).
- T8 node pack is GPL-3.0: runtime-only ComfyUI dependency; open-video code stays Apache-2.0;
  never vendor its code.
- vdn_dmd8 stays opt-in (not default): equal measured quality on this prompt pair, but n=1
  prompt; a broader prompt sweep before flipping defaults is cheap follow-up.
- FreeVideo's 122s/10s third-party claim NOT re-measured (their engine not installed) —
  (unverified, third-party claim). Our 8-step result: 274.6s per 5s @768p on a co-tenanted GPU.
